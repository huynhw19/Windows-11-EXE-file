# BAT Scripts Collection

This folder contains a set of Windows batch scripts for common maintenance, diagnostics, and cleanup tasks on Windows 11.

## Important

- Run scripts as Administrator when required.
- Review each script before executing it on a production system.
- These are examples for learning and testing.

## Scripts

- `01-System-Info.bat` — display basic system information
- `02-Health-Check.bat` — perform quick health checks
- `03-Disable-Telemetry.bat` — disable common telemetry-related tasks
- `04-Reset-Windows-Update.bat` — reset update components
- `05-Network-Reset.bat` — reset network adapters and winsock
- `06-Temp-Cleanup.bat` — remove temporary files
- `07-Remove-OneDrive.bat` — uninstall OneDrive (if applicable)
- `08-Repair-StartMenu.bat` — rebuild Start menu layout
- `09-Disable-GameBar.bat` — disable Game Bar and captured overlays
- `10-Open-Admin-Tools.bat` — open common admin utilities
- `11-Repair-Windows-Store.bat` — reset Microsoft Store components
- `12-Enable-Developer-Mode.bat` — enable developer options
- `13-Disable-Advertising-ID.bat` — disable ad ID and personalized ads
- `14-Explorer-Classic-Mode.bat` — toggle classic Explorer layout tweaks
- `15-Create-Admin-User.bat` — create a temporary admin account
- `16-Quick-Installer-Optional.bat` — install optional common tools

Use them responsibly and adapt them to your environment.
